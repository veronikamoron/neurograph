Node Types

Type Color Description Example
brain_region Cyan Anatomical structure in the brain Hippocampus, Amygdala
tract Magenta White matter pathway Fornix, Corpus Callosum
function Green Cognitive or motor function Memory Consolidation
disorder Red Neurological/psychiatric condition Alzheimer's Disease

Relationship Source Node Target Node Example
